01 · 현재 상태

이번 업데이트는 저장된 점검 기록과 이후 사용자 확인을 종합했습니다. 오늘 이 순간의 서비스 가동·상품 재고를 보장하는 실시간 화면은 아닙니다.

대상상태근거와 한계

안드로이드 알림실제 수신 확인등록된 휴대폰에 시험 알림 1회 발송 후 사용자가 “알림 왔어” 확인.
생활·센서·기록 화면구성됨배곧 생활 대시보드 구성 및 안전한 기록 버튼 시험 완료. 실내 센서는 아직 없음.
기존 VirtualBox 자료보존 기록 확인원본·보관본 10개 파일 비교 결과 변경 없음. 이번 작업은 보고서만 작성.

새로 필요한 것

창문 형태에 맞는 전동 개폐기 1세트 + 열림 센서 1개. 비 감지 센서·끼임 방지·수동 해제 장치도 구성에 포함.

구매 전에 확인

미닫이/여닫이, 폭·무게·잠금장치·방충망·설치 위치 확인. 일반 커튼 모터는 창문 개폐기로 사용할 수 없음. 제품 선정과 설치 방식은 현장 치수 확인 후.

04 · 노트북 켜기 구매 검토

새로 필요한 것

새 노트북을 산다면 Wake-on-LAN 또는 BIOS 예약 켜기 지원을 구매 조건으로 지정. 유선 LAN·도킹 장치는 지원 확인 후 필요한 경우만.

구매 전에 확인

완전 종료/절전 중 어떤 상태에서 켤지 결정. 노트북·BIOS·네트워크 어댑터 조합을 확인하며, USB 랜카드만 구매해도 해결된다고 가정하지 않음.

Home Assistant 연결 계획

Wake on LAN 지원 모델이면 HA에서 깨우기 요청. 실제 켜짐은 별도 상태 확인.

05 · 온습도·공기청정 구매 검토

새로 필요한 것

온습도 센서 1개 + HA 제어가 확인된 공기청정기 1대. 미세먼지 기준 자동화를 원하면 PM2.5 측정값도 필요.

구매 전에 확인

온습도 센서는 먼지를 측정하지 않음. 습도 조절이 목표라면 제습기·가습기가 별도 필요. 공기청정기는 정확한 모델의 원격 전원·풍량 지원 확인.

Home Assistant 연결 계획

온습도 센서는 E1과 지역·모델 호환 확인. 공기청정기는 LG ThinQ 등 지원 통합을 모델별 검증.

완료로 인정할 시험

구매 순서

1단계: T1 1개 + E1로 세탁·건조 시험 → 2단계: 화장실 스위치 구조 확인 후 조명 구성 선정 → 3단계: 음악·온습도·청소·커튼을 예산에 따라 확대 → 4단계: 창문 구동·음성 대화·카메라 기록을 별도 검증.

공유 가능: E1은 호환되는 아카라 센서들에 재사용 가능. 음악·음성 단말은 호환 조건이 맞을 때만 공유. 기존 휴대폰은 알림·사진 입력에 활용. 구동기 개수는 창문·커튼 수와 구조를 확인한 뒤 확정.

08 · 운영 방식과 기록

현재는 G3 Windows의 기존 Docker Desktop 시험 환경에서 접속·로그인·대시보드·휴대폰 알림을 확인했습니다. 이것을 HAOS 복구 완료나 장기 운영 안정성 검증으로 확대하지 않습니다. 재부팅·절전·센서 연결·백업 복구는 각각 검증해야 합니다.

생활 화면은 상태·알림, 센서 화면은 마지막 진동·배터리·연결, 기록 화면은 감지 시각·종료 추정 이유·알림 시도·수신 확인을 구분해 구성할 계획입니다. 별도 DB 수집은 구현되지 않았습니다. HA 내부 DB에 새 표를 직접 추가하지 않습니다.
