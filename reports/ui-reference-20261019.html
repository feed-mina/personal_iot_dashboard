1. 범위와 결론

우선 적용: 생활 화면에는 쉬운 상태 카드, 센서 화면에는 마지막 수신과 연결 상태, 기록 화면에는 판단 근거와 알림 결과를 배치합니다. 분석은 실제 데이터가 쌓인 뒤 추가합니다.

핵심 행동은 “지금 상태를 이해한다 → 이상 이유를 확인한다 → 알림 결과를 검증한다”입니다. 사용자는 집에서 휴대폰으로 보는 본인과, 공개 사례를 읽는 면접관·연구자입니다. 집의 제어 화면과 외부 공개 포트폴리오를 분리합니다.

현재는 Home Assistant 생활·센서·기록 3개 화면과 정적 HTML 보고서가 있습니다. 자체 웹 앱의 프레임워크·API는 확정되지 않았으므로 명세는 프레임워크 중립 제안입니다. 기기 1~2대의 이벤트 중심으로 시작하며 실제 발생량·갱신 주기는 센서 도착 후 측정합니다. 수만 건·1초 갱신을 현재 요구로 가정하지 않습니다.

근거 구분: 공식 문서 설명 / GitHub 파일 확인 / 로컬 설정 확인 / 적용 제안. 이번 조사에서 상용 서비스의 로그인 후 UI·클릭·성능을 직접 검증하지 않았습니다. 아래 모형은 직접 만든 제안이며 제품 캡처가 아닙니다.
