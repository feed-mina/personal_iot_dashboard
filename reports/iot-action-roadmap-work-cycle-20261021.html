03 · 배우고 일정에 넣기

선정·참석 미확인

현재 상황

교육 접수와 선정·실제 참석은 각각 다른 상태입니다. 강의를 듣는 것만으로 센서 성능이 입증되지는 않습니다.

내가 할 일

  1. 선정 통보 후 실제 참석 일정을 기존 work-cycle 주간 스케줄에 기록합니다.
  2. 교육 목표를 “이벤트를 요약하고 근거를 설명하는 작은 도구” 한 가지로 좁힙니다.
  3. 시흥 교육은 첨부 공고의 자격·회차·준비물을 확인한 뒤 신청합니다.

도우미에게 부탁할 말

교육에서 배운 것 중 IoT 로그 요약에 바로 적용할 한 가지와 결과 확인 기준을 정리해줘.

끝났는지 확인하는 법

참석 기록과 적용 결과 1개가 연결됩니다. 수료·선정 상태는 증빙이 있을 때만 기록합니다.

안 되면

행사 일정이 겹치면 무료 교육과 제출 기한을 우선하고 유료 강좌는 필요할 때만 고릅니다.

04 · 센서 1개로 관측

구매·연결 미확인

현재 상황

DJT12LM·SLZB-06U는 후보입니다. 판매자 모델·재고 답변과 실제 구매·도착·연결은 이 보고서에서 확정하지 않습니다.

내가 할 일

  1. 모델·재고가 확인된 후 센서 1개만 준비합니다.
  2. 세탁기와 건조기에 번갈아 붙여 실제 흔들림과 수신 시각을 기록합니다.
  3. 시작·중간 멈춤·종료 시각은 사람이 별도로 기록합니다. 배터리형 진동 센서는 연속 파형 장비로 가정하지 않습니다.

도우미에게 부탁할 말

센서가 도착했어. 실제 감지 간격과 누락 여부부터 확인하고, 중간 정지와 종료를 비교할 실험표를 만들어줘.

끝났는지 확인하는 법

정상 수신·누락·설치 위치에 대한 기록이 있고 실제 종료 정답 시각과 비교할 수 있습니다.

안 되면

수신 누락이면 연결·배터리·거리부터 확인합니다. 반복 수신 빈도가 부족하면 이 센서로 종료 판별이 가능한지 다시 판단합니다.

05 · 종료 추정 검증

실험 예정

현재 상황

휴대폰 시험 알림 수신은 확인됐지만, 세탁·건조 종료 추정 성공은 아직 확인되지 않았습니다.

내가 할 일

  1. 규칙을 정한 기록과 평가할 새 기록을 나눕니다.
  2. 오알림·놓침·지연·통신 끊김을 따로 셉니다. 세탁기와 건조기를 별도 평가합니다.
  3. 사람의 “맞음·아직 진행 중” 확인을 남기고 기준을 바꿨으면 새 회차로 평가합니다.

끝났는지 확인하는 법

일정 시간 조용하다는 이유만으로 완료 처리하지 않습니다. 중간 정지·오래된 관측은 확인 필요로 남깁니다.

C · 실험 요약 연결검토된 센서 실험 요약을 항목에 첨부기록 부담 감소 가설. 통신 끊김·재전송·기록 과다 처리 필요중복 없는 회차 연결, 오래된 데이터 확인 필요, 비밀정보 공개 안 됨

  1. 시범: 생활 IoT 프로젝트 1개와 교육·대회 기회만 로드맵에 넣습니다.
  2. 실행: 로드맵에서 오늘 할 일로 고른 항목만 기존 일정에 연결합니다. 회사용 사이클·기존 완료 규칙·알림 시각은 보존합니다.
  3. 검증: 다른 날 재방문·일정 수정·중복 선택·완료 취소·권한 없음·빈 결과를 확인합니다.
  4. 확장: 사용해 보고 유용하면 취업 준비·학습·포트폴리오도 같은 구조로 묶습니다. 범용화는 실제 불편을 본 뒤 합니다.
